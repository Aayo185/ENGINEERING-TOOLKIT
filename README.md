# Python-Based Engineering Toolkit v1

A simple command-line engineering toolkit built with Python to perform common engineering unit conversions. This project was created to practice fundamental Python programming concepts while developing a useful tool for engineering students.

## Features

* 📏 Length conversions (Kilometers ↔ Miles)
* ⚖️ Mass conversions (Kilograms ↔ Pounds)
* 🌡️ Temperature conversions (Celsius ↔ Fahrenheit)
* 🖥️ Simple menu-driven interface
* ✅ Easy to use

## Technologies

* Python 3
* Visual Studio Code
* Git & GitHub

## Getting Started

```bash
git clone https://github.com/Aayo185/python-based-engineering-toolkit-v1.git
cd python-based-engineering-toolkit-v1
python main.py
```
